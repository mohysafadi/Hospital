# 🏥 Hospital Management System

## 📖 About The Project
A comprehensive desktop application built to manage hospital operations efficiently. It streamlines the process of handling patient records, doctor schedules, and medical treatments.

## ✨ Features
* **Patient Management:** Add, update, and manage patient details.
* **Doctor Records:** Maintain doctor profiles and specializations.
* **Treatment Tracking:** Manage both internal and external treatments.
* **Database Integration:** Secure and reliable data storage using SQL Server.

## 🛠️ Built With
* **Language:** C#
* **Framework:** .NET (Windows Forms)
* **Database:** Microsoft SQL Server

## 🚀 Getting Started
1. Clone the repository: `git clone https://github.com/mohysafadi/Hospital.git`
2. Open the `.sln` file in Visual Studio.
3. Execute the SQL scripts located in the repository to set up the database.
4. Update the connection string in `App.config`.
5. Build and run the project!
